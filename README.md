## 一句話結論
> 在台北市真實規模下，**P7「配對協調」調度**在「服務 vs 成本」效率前緣上**全面支配**其他政策；搭配**按需求配置卡車**可省約 1/3 車隊達標；長期營運再加上**夜間跨區虛擬結算調度**即可維持服務品質的可持續性。

## 專案目標
以**離散事件模擬（SimPy）**重現台北 YouBike 2.0，比較多種卡車調度政策，找出能**最大化服務品質、同時最小化調度成本**的最佳策略（核心指標 **SC Ratio**），並延伸到**長期多日營運**與**跨行政區調度**。
